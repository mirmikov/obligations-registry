# Полное восстановление из локального снимка

Этот каталог содержит зашифрованный снимок локального рабочего состояния на 22 июля 2026 года:

- 1 753 обязательства;
- сумма 536 297 957,52 ₽;
- 6 пользователей;
- 261 справочное значение;
- 28 сообщений чата;
- файлы из тома `chat_uploads`.

Снимок зашифрован, потому что GitHub-репозиторий публичный. Ключ хранится отдельно от GitHub.

После клонирования репозитория создайте `.env`, укажите собственные секреты и обязательно установите `RUN_DATABASE_MIGRATIONS=false`. Затем запустите:

```bash
chmod 600 .env
CONFIRM_REPLACE_DATABASE=YES ./ops/bootstrap/restore-local-snapshot.sh
```

Скрипт интерактивно запросит ключ, создаст страховочную копию существующей серверной базы, полностью заменит её содержимое снимком, восстановит файлы чата, соберёт приложение и проверит `/api/health`.

Команда намеренно перезаписывает серверную базу. Для обычных последующих обновлений используйте `./ops/production/update-from-github.sh main`.
