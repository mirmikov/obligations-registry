# Уведомления реестра обязательств для Windows

Небольшое приложение без окна в панели задач. После входа оно остаётся в системном трее, автоматически запускается вместе с Windows и показывает собственные всплывающие окна о новых сообщениях.

## Возможности

- уведомления о личных, групповых сообщениях и счетах, отправленных в бухгалтерию;
- переход по клику сразу в нужный чат веб-реестра;
- универсальный серверный endpoint для будущих уведомлений других подсистем;
- автозапуск текущего пользователя без прав администратора;
- приостановка, ручная проверка связи и смена пользователя из меню трея;
- автоматическая проверка новой версии и установка по кнопке «Обновить» без повторного запуска установщика;
- пароль не хранится; 30-дневный ограниченный desktop-токен зашифрован Windows DPAPI и не принимается обычными API реестра;
- первый запуск начинает с текущего момента и не показывает всю старую историю.
- команда Проводника «Сканировать в ФинРеестре» для PDF, PNG и JPEG: файл сразу отправляется в AI-сканирование, а результат открывается в веб-реестре.

## Сборка

На Windows с .NET SDK 10:

```powershell
.\build.ps1
```

Готовый архив: `dist\RegistryNotifier-win-x64.zip`. Распакуйте архив на компьютере сотрудника и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Приложение устанавливается в `%LOCALAPPDATA%\Mirt\RegistryNotifier\App`, не требует прав администратора и сразу добавляет себя в автозапуск текущего пользователя. Для массовой установки тот же архив можно развернуть через GPO/Intune; перед широким распространением рекомендуется подписать `RegistryNotifier.exe` корпоративным сертификатом подписи кода.

Начиная с версии 1.2.0 последующие выпуски устанавливаются автоматически: приложение проверяет опубликованный сервером манифест, показывает окно «Доступно обновление», загружает пакет по HTTPS и перед заменой exe сверяет размер, SHA-256 и версию файла. Настройки, desktop-токен и автозапуск сохраняются. Для уже установленных версий 1.1.0 и ниже требуется один раз установить пакет 1.2.0 — в них механизма самообновления ещё не было.

После установки нажмите правой кнопкой мыши на PDF, PNG или JPEG. В Windows 11 команда может находиться в разделе «Показать дополнительные параметры». Выберите «Сканировать в ФинРеестре»: приложение проверит размер и тип файла, использует защищённую desktop-сессию и откроет карточки распознавания в реестре. Сохранение строк остаётся ручным — бухгалтер сначала проверяет распознанные значения.

## API расширения

`POST /api/desktop/notifications` доступен только пользователю «Программист». Тело:

```json
{
  "kind": "registry.approval",
  "title": "Обязательство утверждено",
  "body": "Счёт № 17 переведён в статус «К оплате»",
  "action_url": "/?page=registry",
  "user_ids": [15]
}
```

Пустой `user_ids` означает всех активных пользователей. `action_url` допускает только относительный путь внутри этого же реестра. Будущий backend может добавлять строки в `desktop_notifications` в своей транзакции тем же способом, которым сейчас подключены сообщения.
