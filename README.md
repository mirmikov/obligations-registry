# ФинРеестр — реестр обязательств

Сервис заменяет исходную книгу «Реестр обязательств.xlsx»: единый реестр из 17 полей, рабочие справочники, устойчивые персональные фильтры, реестр к оплате, управленческая панель, импорт/экспорт Excel, внутренний чат и журнал действий.

В реестре отображаются активные пользователи: наведение на аватар показывает имя, а нажатие — открытую запись, исходную строку Excel и редактируемое поле. Состояние обновляется автоматически, неактивные подключения исчезают примерно через 18 секунд.

Реестр редактируется прямо как электронная таблица: плюс в шапке создаёт строку, клик открывает ячейку, а `Enter` или переход в другую ячейку автоматически сохраняет данные. Справочные значения выбираются через списки с поиском, даты отображаются в формате `дд/мм/гггг` и назначаются через собственный календарь.

В разделе «Чаты» каждый пользователь может открыть личный диалог с коллегой или создать группу. История сообщений хранится в PostgreSQL, доступна только участникам и автоматически обновляется без перезагрузки страницы. После включения разрешения браузер показывает системные уведомления о новых сообщениях, пока сервис открыт во вкладке — в том числе когда она находится в фоне или окно браузера свёрнуто.

## Запуск

1. Скопируйте `.env.example` в `.env` и обязательно замените пароли и `JWT_SECRET`.
2. Запустите:

```bash
docker compose up --build -d
```

3. Откройте [http://localhost:8088](http://localhost:8088).

При первом старте PostgreSQL автоматически получает все 1 521 рабочую строку исходного реестра, справочники и 453 заметки об условиях оплаты.

## Вход администратора

При первом запуске создаётся администратор:

| Логин | Пароль |
|---|---|
| `admin` | `Qazxsw21` |

Администратор управляет пользователями и справочниками, импортирует Excel и может удалять записи. Дополнительных редакторов и зрителей он создаёт в разделе «Пользователи».

## Резервное копирование

```bash
docker compose exec -T db pg_dump -U registry registry > registry-backup.sql
```

Восстановление выполняется в пустую базу командой `psql -U registry registry < registry-backup.sql`.

## Локальная разработка

Backend:

```bash
cd backend
DATABASE_URL='postgres://registry:registry@localhost:5432/registry?sslmode=disable' go run ./cmd/server
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Vite проксирует `/api` на `localhost:8080`.
